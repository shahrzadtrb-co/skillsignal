# SkillSignal

SkillSignal collects tech job postings in Germany and counts which skills they ask for, showing exactly how each number was calculated.
It is for early-career developers who want to know what jobs in their target role really require.
Job data comes from the free [Arbeitnow Job Board API](https://www.arbeitnow.com/api/job-board-api). Raw descriptions stay private and only aggregate counts are published.
Work in progress: currently building the data fetcher and validation.
